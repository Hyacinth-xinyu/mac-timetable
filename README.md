# 课表

一款使用 SwiftUI 构建的 macOS 课表应用。通过周视图管理课程，也可以从菜单栏快速查看今天的安排和下一节课。课表和设置保存在本机，无需账号。

## 功能

- **周课表**：按教学周查看课程，支持切换周次、查看课程信息，以及手动添加、修改和删除课程。
- **线上授课标记**：地点注明线上授课的课程会在课表和菜单栏中突出显示，也可以在编辑课程时手动标记。
- **多人课表**：在主窗口或菜单栏切换不同人的课表；每份课表分别保存课程、学期和作息。
- **Word 导入**：读取特定格式的 `.docx` 课表，识别周次、单双周和同一单元格中的多组安排；导入前可逐条核对和修改。
- **导出日历**：将整个学期的课程导出为 `.ics` 文件，随后可导入苹果日历。
- **菜单栏快捷查看**：显示当天课程和接下来的课程，并可打开完整课表。
- **作息与提醒**：设置第一教学周、每节课的时间和统一的课前提醒；可选择登录时自动启动。
- **本地存储**：课程和设置保存在当前 Mac 的应用支持目录中，导入过程在本机完成。

## 系统要求

- macOS 13 或更新版本。
- 从源码构建需要 Xcode 15 或更新版本，及其 Swift 工具链（Swift 5.9 或更新版本）。

## 从源码构建

下载或克隆仓库，在项目目录的终端中运行：

```bash
./Scripts/build-app.sh
open "build/课表.app"
```

脚本使用 Swift Package Manager 编译，生成图标并创建应用包。生成的应用使用本地临时签名，未经过 Apple 公证；首次在其他 Mac 上运行时，macOS 可能提示无法验证开发者。

运行测试：

```bash
swift test --disable-sandbox
```

构建脚本和上述测试命令关闭了 Swift Package Manager 的清单沙盒；运行前请检查所使用的源码。

## 使用方法

1. 打开应用，点击“导入”选择 Word 课表，或点击“添加”手动创建课程。
2. 在设置中填写第一教学周的日期，并检查各节课的起止时间。初始作息为西北工业大学 2026–2027 学年长安校区时间，可根据实际情况修改。
3. 导入时检查识别出的课程、地点、教师和周次；确认后，新课表会替换现有课表。
4. 点击屏幕顶部菜单栏中的日历图标和“课表”，快速查看课程或打开完整课表。菜单栏空间不足时，可点击 Dock 中的应用图标恢复窗口。

点击窗口红叉、按 Command-Q 或选择应用菜单中的“退出”会收起窗口，应用继续在菜单栏运行。需要结束应用时，请在菜单栏面板中选择“完全退出”。

如需课前提醒，请在设置中启用提醒并允许系统通知。系统可预先安排的通知数量有限，保持应用运行可以持续更新后续提醒；开机自动启动默认由用户选择。

点击“导出日历”可保存整个学期的 `.ics` 文件，在苹果日历中打开并选择要导入的日历。文件是保存时的课表快照，后续在课表应用中更改课程不会自动同步，重复导入可能产生重复日程。导出时若已开启课表提醒，日历日程也包含相同的课前提醒；两个应用同时开启提醒可能产生重复通知。

线上课程的日历标题会带有“[线上]”标记，地点或授课链接保持原样。已有日历文件不会自动更新，需重新导出后再导入。

点击主窗口左上角的课表名称，在“管理课表”中新建、重命名或删除其他人的课表；顶部菜单栏也可切换。新课表初始使用“我的课表”的学期日期和作息，可单独修改。应用只提醒“我的课表”的课程；导出仅包含当前所选课表，其他人的导出文件不包含提醒。

## 导入格式与限制

目前仅支持与已适配样式相同的 `.docx` 表格：表头包含“星期一”至“星期日”，课程内容包含周次和节次，例如 `(1~16周)(1-2节)`。支持单周、双周及同一课程文本内的多组周次安排；不支持任意 Word 排版、旧版 `.doc`、PDF 或图片识别。

导入预览会列出跳过的内容，并保留原文供核对。缺少具体上课时间或无法识别的课程需要手动补充；请在确认导入前检查所有结果。
